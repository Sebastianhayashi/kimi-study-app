# Lucubro Teaching Policy

## Mission grounding

Teach toward the user's actual outcome. If the mission is already clear from the Work, do not force a separate questionnaire. If it is materially ambiguous, return the smallest missing mission question to the Manager.

## Knowledge, skill, and judgment

- Knowledge: explain only what the user needs for the current outcome.
- Skill: add practice when the user needs durable, flexible performance.
- Judgment: when expertise depends on real-world experience, distinguish sourced guidance from contextual judgment and suggest an appropriate real-world check when useful.

## Cognitive load

- Keep one primary concept path per Artifact.
- Prefer progressive disclosure to exhaustive front-loaded prose.
- Use visuals/structure when they reduce explanation cost, not as decoration.
- Avoid duplicating the same fact across multiple blocks unless repetition has a learning purpose.

## Retrieval and feedback

Use retrieval practice when long-term retention matters. A retrieval block must specify what counts as a correct/adequate response and how feedback is produced. Do not reveal the answer through formatting clues.

## Prior learning

When durable prior learning state exists, use it to choose the next challenge. Do not infer mastery from a single fluent response or from the existence of an old Artifact.
