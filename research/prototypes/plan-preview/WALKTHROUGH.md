# Structured walkthrough record

These are five deterministic task walkthroughs against the read-only prototype. They are scenario checks, not claims of moderated human research.

## Walkthrough 1: missing source coverage

The reviewer compares the source digest with the three coverage fields and can identify that a source chapter is absent. The approval boundary remains visible: full generation has not started and no correction is saved.

## Walkthrough 2: objective does not match the mission

The reviewer compares the Teach Mission with each objective and can flag a lesson that only summarizes instead of requiring judgement or transfer. The approval boundary is understood before any generation action.

## Walkthrough 3: practice is too passive

The reviewer sees that each lesson exposes planned practice beside its objective. A read-only or recall-only exercise can be identified as a mismatch without opening a generated lesson.

## Walkthrough 4: sequence is premature

The reviewer checks whether recognition precedes judgement and transfer. A transfer task placed before source understanding can be identified from the visible sequence. The prototype still offers no write or approve control.

## Walkthrough 5: plan is acceptable

The reviewer can state what the plan covers, what it does not cover, and that the next production decision would require a separately approved persistence and generation contract. This confirms the approval boundary rather than implying P2-10 is authorized.

## Result

All five scenarios expose a correction opportunity and preserve the read-only boundary. This supports a later moderated test, but does not by itself authorize persistent plan state or a server API.
