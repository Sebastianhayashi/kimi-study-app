# Kimi Study 产品模型

## 一句话定义

Kimi Study 把一本书或一组学习材料，转化为一条可以执行、检查和继续推进的个人课程路径。

它的核心不是“生成更多内容”，而是让用户完成以下闭环：

```text
理解学习目标
→ 获得合适的学习顺序
→ 在课节中行动
→ 暴露误区和理解缺口
→ 获得基于当前材料的帮助
→ 用学习记录决定下一步
```

## 目标用户

- 想系统读懂一本专业书，但无法设计学习顺序的人；
- 需要从自己的教材、报告或内部文档学习的人；
- 希望 AI 助手始终绑定当前材料，而不是泛泛聊天的人；
- 正在探索 AI 原生课程、互动课件和个性化学习路径的开发者。

## 核心对象

### Source

用户上传的 PDF、EPUB、Markdown 或文本。Source 是课程依据，不是一次性 Prompt 附件。

### Mission

课程生成前的学习契约，包含目标、完成标准、约束、受众和重点。Mission 用于限制生成范围，并给 Tutor 和下一课生成提供长期上下文。

### Course map

把材料结构、关键概念、方法和学习路径组织成用户可理解的地图。

### Lesson

可在浏览器中运行的互动课节。它可以包含正文、引导问题、选择题、提示、反馈、学习卡片和与原文的链接。

### Learning record

记录课节访问、活动尝试、掌握证据、误区、笔记和课程状态。它用于恢复学习，也用于决定下一课内容。

### Tutor session

绑定课程和课节的连续 Kimi 会话。Tutor 的上下文由 Mission、当前课节、原始材料引用、笔记、掌握情况和误区组成。

## 产品原则

1. **行动优于摘要**：每个课节应该让用户做出判断、解释、迁移或练习。
2. **来源优于泛化**：Tutor 优先使用当前课程与材料证据。
3. **状态必须一致**：页头、侧栏、主内容和 Tutor 不得对同一工作流表达冲突状态。
4. **进度来自证据**：生成进度由后端阶段和已发布产物推导，不伪造剩余时间。
5. **失败也是终态**：失败或中断必须停止动画、解释原因并提供下一步。
6. **课程是持久产物**：Mission、课节、评估、笔记和记录可检查、恢复和继续生成。

## 与常见工具的区别

| 工具类别 | 通常产物 | Kimi Study 重点 |
|---|---|---|
| 文档摘要 | 一段浓缩文本 | 学习目标、顺序、课节、练习和下一步 |
| 通用聊天机器人 | 当前会话回答 | 课程级长期上下文和材料依据 |
| 静态在线课程 | 固定课程结构 | 从用户材料和目标生成个人路径 |
| 题库工具 | 独立题目 | 题目与课节概念、误区和迁移证据关联 |
| 阅读器 | 阅读、搜索、标注 | 阅读器与课程、Tutor、笔记和活动联动 |

## 当前产品边界

Kimi Study 是本地运行的研究型原型。它不包含生产级账户体系、多人权限、支付、云端任务队列或服务级可用性承诺。模型调用依赖用户自己的 Kimi CLI 登录和服务配置。
