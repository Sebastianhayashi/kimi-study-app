# 已知限制

## 运行环境

- 需要 Node.js 22+。
- 真实课程生成和 Tutor 依赖已安装、已登录的 Kimi CLI。
- 应用没有内置云端密钥管理、任务队列或多租户隔离。

## 材料兼容性

- PDF.js 和 EPUB.js 的真实文件兼容性取决于浏览器、资源路径、字体和文件结构。
- 当前 Fixture 不能代表所有扫描 PDF、超大文件、复杂 EPUB、加密文件或损坏文件。
- OCR 不在当前默认路径中。

## 模型非确定性

- 同一材料可能生成不同课节表达。
- 测试验证结构、状态、安全和质量条件，不要求模型逐字输出一致。
- 真实学习效果仍需要目标用户研究，不能仅由自动测试证明。

## 产品范围

当前没有：

- 生产级账号、团队和权限；
- 支付、订阅或额度系统；
- 云端课程同步；
- 多实例任务调度；
- 完整国际化；
- 面向学校或企业的管理后台。

## 安全与隐私

课程文件默认保存在本地数据目录，但真实模型调用会通过用户的 Kimi CLI 和其配置的服务。不要上传无权处理的敏感材料。公开 Issue、Trace、截图或报告前，请检查是否包含原始材料、课程内容、文件路径或会话信息。

## 命名

Lucubro 是独立开源实验项目，不是 Moonshot AI 的官方产品。
