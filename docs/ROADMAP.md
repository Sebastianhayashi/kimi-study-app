# 路线图

## P0：可靠的核心旅程

- 扩大 PDF/EPUB Fixture 矩阵；
- 完成 Chromium、Firefox、WebKit 核心旅程；
- 对 Console、Network、404/5xx 建立统一守卫；
- 确保所有终态使用单一状态快照；
- 为下一课和 Tutor 失败路径补齐真实浏览器回归。

## P1：学习效果

- 使用真实目标用户验证 Mission 的可理解性；
- 改进概念掌握、误区与迁移证据的可视化；
- 让下一课更明确地响应已完成活动与薄弱概念；
- 建立课程质量评测集，而不是只评估 HTML 合法性；
- 研究“资源 / 原文 / 任务 / 方法速查”的命名和信息层级。

## P1：阅读与笔记

- 更完整的 PDF 搜索、目录、缩放和错误恢复；
- EPUB 位置和主题持久化；
- 原文锚点在内容变化后的恢复策略；
- 笔记导出与课程级搜索。

## P2：产品化

- 可选的本地账户或单用户身份；
- 课程导入、导出和迁移；
- 后台任务队列与断点续跑；
- 多模型适配层；
- 安装器、Docker 和受控部署文档；
- 完整中英文界面。

## 暂不承诺

- 用更多生成动画代替真实进度；
- 在没有用户研究前增加大量一级按钮；
- 让测试依赖模型每次输出相同文本；
- 为了测试通过而吞掉错误或隐藏失败状态。
