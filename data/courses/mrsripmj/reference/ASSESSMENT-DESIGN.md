# 教材测评设计

## 1. 学习主张（Learning Claims）

### 1.1 单元级学习主张

| 单元 | 核心主张 | 对应教材页码 |
|------|----------|--------------|
| Unit 1 Our Classroom | 学生能够用英语描述教室物品并表达所在班级。 | 3–8 |
| Unit 2 Our School | 学生能够询问和回答所在班级，并介绍学校场所。 | 9–14 |
| Unit 3 Numbers and Animals | 学生能够用 13–20 的数字描述农场动物数量，并做简单加法问答。 | 16–21 |
| Unit 4 Numbers and Time | 学生能够用整点与半点表达方式询问和回答时间。 | 22–29 |
| Unit 5 Daily Activities | 学生能够用整点时间描述日常作息。 | 30–35 |
| Unit 6 Meals | 学生能够询问三餐吃什么，并表达喜好与招待。 | 36–41 |
| Unit 7 Christmas | 学生能够用英语表达圣诞愿望、祝福并书写圣诞卡。 | 42–47 |
| Unit 8 The Spring Festival | 学生能够用英语描述春节活动并对比中西方节日。 | 48–53 |

### 1.2 全书跨单元主张

1. **词汇识记**：学生能在图片或中文提示下，正确认读并拼写教材词汇表中的核心词。
2. **句型运用**：学生能在真实或模拟情境中，正确使用各单元核心问答句型。
3. **语音意识**：学生能识别教材中反复出现的字母及字母组合发音，做到听音辨词、见词能读。
4. **文化意识**：学生能比较 Christmas 与 the Spring Festival 的节日习俗与英语表达。
5. **学习策略**：学生能借助歌曲、歌谣、评价表等工具进行自我检测与复习。

## 2. 证据要求（Evidence Requirements）

每项主张需要以下类型的证据：

| 证据类型 | 说明 | 采集方式 |
|----------|------|----------|
| 选择/匹配 | 从多个选项中选出正确的词义、图片或答句。 | HTML 中的选择题 |
| 填空拼写 | 根据中文或图片提示写出英文单词或句子的缺失部分。 | HTML 中的填空题 |
| 排序 | 将对话、句子或图片按正确逻辑顺序排列。 | HTML 中的排序题 |
| 朗读/复述 | 学生口头朗读课文或复述情境。 | 由教师/家长听评，或自评 |
| 书写表达 | 写一段 5–8 句的短文描述教室、学校或节日。 | 课后作业/学习记录 |

## 3. 测评蓝图（Assessment Blueprint）

### 3.1 题型与分布

| 题型 | 每课题数 | 考查重点 | 自动评分 |
|------|----------|----------|----------|
| 词汇选择 | 3–4 | 词义、图文匹配 | 是 |
| 句型选择 | 2–3 | 问答对应、情境判断 | 是 |
| 填空拼写 | 2–3 | 单词拼写、句型补全 | 是（完全匹配） |
| 排序 | 1 | 对话逻辑顺序 | 是 |
| 听力/朗读 | 1（不计分） | 语音语调 | 否（自评） |

### 3.2 评分规则

- 每题分值 1 分。
- 填空题不区分大小写，但拼写必须正确。
- 排序题必须所有元素位置完全正确才得分。
- 达到总分的 80% 视为本课达标。

## 4. 常见误解（Misconceptions）

1. **班级与年级顺序**：英语先说班级（Class）再说年级（Grade），与中文“四年级一班”顺序相反。
2. **数字 teen 与 ty**：thirteen / thirty, fourteen / forty 等容易混淆。
3. **时间的整点与半点**：“九点半”是 half past nine，不是 half to ten。
4. **三餐介词**：at breakfast / lunch / dinner，不是 in breakfast。
5. **节日表达**：说“春节快乐”用 Happy New Year 或 Happy Spring Festival，而 Merry Christmas 只用于圣诞节。
6. **do 的用法**：Do you like...? 是一般疑问句，回答用 Yes, I do. / No, I don't.，而不是 Yes, I like.

## 6. 质量报告（Quality Report）

### 6.1 材料完整性

- 扫描 PDF 共 44 页，包含封面、致同学、目录、8 个单元、2 个复习、词汇表和封底。
- 部分页面因扫描和 OCR 识别存在少量噪音，但核心文本、词汇表和句型已可辨识。
- 教材配套音频未包含在 PDF 中，学习时建议额外准备听力材料。

### 6.2 测评可评分性

- 普通选择、填空、排序题均设计为确定性评分，答案与评分键存放于 `assessments/`。
- 主观朗读/书写题由学习者自评或教师评定，不计入自动评分。
- 填空题通过字符串归一化（去除多余空格、统一小写）降低因格式差异导致的误判。

### 6.3 改进建议

- 后续课时可根据学习者作答数据调整题目难度。
- 对于语音题，可补充录音示例或音标提示。
- 节日单元可补充文化对比图片，增强情境感。
